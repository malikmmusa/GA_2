# Skill: Planner (The Architect)
**Trigger:** When asked to "plan", "design", or "break down" a task.

## Protocol
1. **Medical Validity Check:** - Does this approach align with retinal anatomy (e.g., fovea is temporal to the disc)?
   - Are we handling pathologic cases (GA) vs. normal anatomy?

2. **Machine Learning Strategy:**
   - Define the Model Architecture (e.g., U-Net, ResNet-50, ViT).
   - Define the Loss Function (e.g., Dice Loss for segmentation, MSE for detection).
   - Define the Metrics (e.g., IoU, AUROC).

3. **Output Format:**
   - Create or update `TODO.md` in the root.
   - Break work into atomic steps (< 50 lines of code each).
   - **NO CODE** is allowed in this phase. Only pseudocode or specs.
